# Блокнот целей (Android)

Приложение для Android 8.0 и новее, на Kotlin и Jetpack Compose. Работает без интернета, все данные хранятся на телефоне.

## Что умеет

- **Заметки**: записывай всё, что нужно, ищи по тексту. Изменения сохраняются при выходе из заметки.
- **Цели**: название, описание («зачем мне это») и **путь к цели**, то есть список шагов с галочками и прогресс-баром.
- **Ежедневное напоминание**: в выбранное время приходит уведомление с названием цели, следующим невыполненным шагом и номером дня на пути к цели. Нажми на уведомление, и откроется цель.
- Напоминания восстанавливаются сами после перезагрузки телефона.
- Кнопка «Показать пробное уведомление» — чтобы проверить, что уведомления работают.

## Как собрать APK

### Вариант 1: GitHub Actions (не нужно ничего устанавливать)
1. Создай новый репозиторий на GitHub и загрузи туда содержимое этой папки:
   ```bash
   cd GoalNotes
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin git@github.com:<твой-логин>/GoalNotes.git
   git push -u origin main
   ```
2. Открой вкладку **Actions** и дождись, пока завершится сборка «Build APK» (около 3–5 минут).
3. Внизу страницы сборки, в разделе **Artifacts**, скачай `GoalNotes-apk`. В zip-архиве лежит `app-debug.apk`.

### Вариант 2: Android Studio
1. Открой папку `GoalNotes` через File → Open и дождись синхронизации Gradle.
2. Собери APK через Build → Build App Bundle(s) / APK(s) → Build APK(s) или запусти приложение на телефоне по USB.

Из терминала (если установлен Android SDK): `./gradlew assembleDebug`. APK появится в `app/build/outputs/apk/debug/`.

## Установка на телефон
1. Скопируй `app-debug.apk` на телефон и открой его.
2. Разреши установку из этого источника.
3. При первом запуске разреши уведомления.
4. На Android 12 и новее, если хочешь получать напоминания точно минута в минуту, на экране цели нажми «Открыть настройки» и включи «Будильники и напоминания».
5. На Xiaomi, Huawei, Samsung и других телефонах с агрессивным энергосбережением стоит выключить для приложения оптимизацию батареи. Иначе напоминания могут опаздывать.
